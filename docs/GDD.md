# [TD_SHOOT_ROUGELIKE] 기획 및 시스템 아키텍처 명세서

> 이 문서는 프로젝트의 기준 문서(GDD)입니다.
> 1~7장은 Google AI Studio 단계에서 확정한 **원본 기획**이고, 8장은 Claude Code 도입 시점(2026-10-16)의 **코드 현황과 미정 사항**입니다.
> 코드와 이 문서가 다르면 임의로 판단하지 말고 알려주세요.

## 1. 프로젝트 개요

- 개발 환경: Unity 6 (6000.5.5f1), Universal Render Pipeline (URP 3D)
- 장르: 탑다운 3D 액션 슈팅 로그라이크 + 익스트랙션(탈출) 루프 + 테트리스 공간 인벤토리 빌딩
- 개발 목적: 졸업작품용 인디 슈팅 로그라이크 완성
- 학술/기술적 핵심 어필 주제
  1. 2D 행렬 연산 및 ScriptableObject 기반 테트리스 공간 인벤토리 아키텍처
  2. BSP(이진 공간 분할) 알고리즘 기반 절차적 3D 아레나 생성 및 런타임 NavMesh 동적 베이킹

## 2. 플레이어 조작 및 사격

### 2-1. 이동 및 회피 (대시)

- 기본 이동: WASD 8방향 이동
- 대시 회피 (Dash Dodge)
  - 점프를 차단하고, Space 입력 시 이동 방향(WASD) 또는 정면으로 순간 대시
  - 수치: 이동 거리 5m, 소요 시간 0.15초, 쿨타임 0.6초
  - 상체 조준/사격 모션은 유지하고 하체만 슬라이딩
  - 카메라 기준(Camera-Relative) 방향 보정 적용 (화면상 WASD 방향으로 직관적 대시)

### 2-2. 수평 조준 및 사격

- 상시 조준 (Always Aiming): 우클릭 조준 없이 마우스 커서 방향을 항상 조준
- 무한 수평 평면 레이캐스트 (Plane.Raycast)
  - 지형/몬스터 콜라이더에 의해 조준선이 튀는 것을 막기 위해, 플레이어 가슴 높이(Y = 1.2m)의 가상 수평 평면에 마우스 레이를 투사
  - 총알은 바닥과 100% 수평으로 직진
- 맨손 금지: `AllowBareHands = false`, 항상 무기를 든 상태 유지

## 3. 무기 아키텍처

### 3-1. 소지 및 탄약 규칙

- 주무기 슬롯 2개 (1번, 2번), E키로 실시간 교체
- 무제한 예비탄
  - 사격 시 탄창(BulletsAmounts) 1발씩 차감, 소진 시 R키 재장전 필수 → **정정 (8-6 #17)**: 탄창이 0발이 되면 자동 장전 (JU 기본 기능 `_AutoReload`, 전 무기 확인). R키는 탄이 남았을 때 미리 장전용
  - 재장전 시 예비탄(TotalBullets)을 차감하지 않고 탄창을 가득 채움

### 3-2. 4대 무기군 / 11종

> **변경됨 (8-6 #6)**: 무기는 에셋 외형 기준 5종으로 축소. 아래 11종은 원본 기록으로 보존하며, 모듈 조합 빌드로 재현합니다.

**권총군 (3종)**
- 리볼버: 6발 고정, 느린 연사, 높은 단발 피해, 기본 도탄(Ricochet) 패시브
- 쌍권총 (P226 Dual): 빠른 연사, 많은 타수, 확률적 탄환 미소모 (회수/Recycle) 패시브
- 소형 기관권총: 초근접 순간 폭딜, 빠른 장전, 넓은 탄퍼짐

**산탄총군 (3종)**
- 더블배럴 샷건: 2발 탄창, 강력한 근접 넉백/광역 피해, 초고속 재장전 (재장전 속도 모듈과 시너지)
- 자동 산탄총: 드럼 탄창, 연속 사격, 탄창 확장 모듈 적용 가능
- 펌프액션 샷건: 1발씩 쉘 장전, 균형 잡힌 집탄율/피해

**자동소총군 (3종)**
- 표준 자동소총: 30발, 페널티 없는 기준 무기
- 전술 버스트 소총: 3점사 정밀 사격, 기본 도탄 패시브
- 경기관총 (LMG): 100발, 지속 사격 시 연사력 예열 가속, 이동속도 약간 감소

**저격총군 (2종)**
- 대구경 대물저격총 (SNIPER M82): 1발 볼트액션, 모든 적 관통, 착탄 시 범위 폭발
- 지정사수소총 (DMR): 반자동, 10발, 적절한 사격 속도와 관통력

### 3-3. 수류탄 스킬

> **변경됨 (8-6 #11)**: G키만 사용, Q키는 미사용.

- 무기 슬롯과 별개의 독립 스킬, G키(또는 Q키)
- 최대 2회 충전, 기본 쿨타임 10초 (테트리스 모듈로 감소 가능)

## 4. 테트리스 강화 모듈 및 그리드

### 4-1. 그리드 규칙

- 기본 8x8 (64칸), 메타 프로그레션으로 최대 10x10까지 확장
- R키: 90도 시계방향 회전 (RotateShapeClockwise). 좌우/상하 반전(Flip) 금지
- 모듈 크기
  - 소형 (1~2칸): 자투리 채우기용, 낮은 수치
  - 중형 (3~4칸): L, T, 2x2, Z, I 표준 모듈
  - 대형 (5~6칸): 공간을 많이 차지하나 압도적 성능

### 4-2. 모듈 분류

> **변경됨 (8-6 #7)**: 스탯 / 작동 / 특수 / 유니크 4계열로 재편. 아래는 원본 기록입니다.

- Type A (스탯 강화): 공격력 %, 최대 체력 +, 방어력 +, 이동속도 %, 장전속도 %, 연사력 %, 치명타 확률 %, 수류탄 쿨타임 감소 %
- Type B (메커니즘 조건부): 재장전 시 폭발, 탄환 환수, 체력 30% 이하 적 처형, 탄창 마지막 탄환 추가 피해
- Type C (유니크 교차): 특정 무기군에 새 메커니즘 부여 (예: 권총 사격 시 미사일 발사, 산탄총 도탄 적용)

### 4-3. 레어도 4단계 (원본 기획 계수)

| 레어도 | 색상 | 수치 계수 |
|---|---|---|
| 일반 (Common) | 흰색 | 1.0x |
| 희귀 (Rare) | 파란색 | 1.4x |
| 엘리트 (Elite) | 보라색 | 1.9x |
| 레전더리 (Legendary) | 노란색 | 2.5x + 특수 부가 효과 |

> 현재 코드는 1.0 / 1.3 / 1.7 / 2.5입니다. 8장 참고.

## 5. 필드 드랍 및 자동 수거

### 5-1. 필드 드랍

> **변경됨 (8-6 #5)**: 일반 적은 모듈만, 엘리트는 무기를 확정 드랍합니다.

- 적 사망 시 확률적으로 레어도 색상(흰/파/보/노)으로 빛나며 회전하는 3D 드랍 상자 생성

### 5-2. 자석 자동 수거 (Auto-Vacuum)

- 라운드 클리어 순간, 미수거 드랍 전부가 플레이어 가슴 위치로 거리 비례 가속 비행 (StartFlyingToPlayer)
- 플레이어와 부딪히면 축소되며 인벤토리로 수거
- 일시정지 시 공중 아이템 유실 방지용 강제 수거 안전망 (EnsureAllItemsCollected)

## 6. 드랍 확률과 탈출 루프

### 6-1. 드랍 확률 감쇄 및 HUD

- 시작 드랍률: 스테이지 진입 시 35.0%
- 아이템 1개 획득마다 -5.0%
- 최소 보장(Floor): 0.5%
- HUD: 좌측 상단에 `드랍률: XX.X%` 실시간 표시

### 6-2. 초반 제한형 천장 (Limited Early Pity)

- 스테이지 진입 후 최초 2회 드랍까지만, 3연속 미드랍 시 100% 확정 드랍
- 2회 달성 후 천장 비활성화, 감쇄 확률(최저 0.5%)에 의존

### 6-3. 탈출 구역 (Extraction Zone)

- 맵의 무작위 위치에 지름 10m의 파란 반투명 원형 구역 생성
- 플레이어가 구역 안에 있을 때만 60초 카운트다운, 밖으로 나가면 일시정지, 다시 들어오면 이어서 차감
- 60초 달성 시: "EXTRACTION SUCCESSFUL" 출력 → 주변 적 전체 디스폰 → 전리품 자석 수거 → 2.5초 대기 → 정비 단계 진입

### 6-4. 목숨 (Lives)

> **보완됨 (8-6 #2)**: 정비 후에는 실패한 라운드를 다시 시도합니다 (라운드 번호 유지).

- 총 3개 (Lives = 3)
- 사망 시: "MISSION FAILED" 출력 → 주변 적 전체 디스폰 → 2.5초 대기 → 목숨 1 차감
- 목숨이 남아 있으면 체력 100% 복구 후 정비 단계 진입
- 목숨 0이 되면 최종 게임 오버

### 6-5. 무한 난이도 스케일링

- 스테이지 경과 시간에 따라 적 체력 분당 +25%, 공격력 분당 +20%
- 적 이동속도 분당 +5%, **최대 +30% 상한(Cap)** (이동 경로 차단 방지)

## 7. 정비 단계 UI/UX

### 7-1. 화면 레이아웃

- **좌측 (전리품 가방)**
  - 무기: 상단 우선 정렬, 가로 와이드 배너 (260 x 85)
  - 강화모듈: 무기 하단, 80x80 정사각 타일, 표면에 2D 미니 테트리스 형태 + 검은 아웃라인
- **중앙 (8x8 그리드)**
  - 64개 타일, 안착 모듈에 레어도 색상 칠하기
  - 드래그 시 커서를 모듈 정중앙에 고정, R키 제자리 90도 회전, 안착 유효성 하이라이트 (초록/빨강)
- **우측**
  - 장착 무기 슬롯 2개: 두께 2배 (120px), 레어도 배경색과 이름 표기
  - 금고 슬롯 3개: 무기와 모듈 보관 가능
- **하단**: "NEXT ROUND" 버튼

### 7-2. 인벤토리 조작 및 안전망

- 단일 위치 원칙: 아이템은 가방 / 장착 슬롯 / 금고 / 그리드 / 마우스 손 중 **한 곳에만** 존재
- 손 스왑: 아이템을 든 채 이미 아이템이 있는 슬롯을 클릭하면 기존 아이템이 손으로 튀어나와 교체
- 가방 클릭 반납: 아이템을 든 채 좌측 가방 영역 클릭 시 가방으로 이관
- 선제적 자동 원복: 아이템을 든 채 가방의 다른 아이템을 누르면 들고 있던 것을 먼저 가방에 원복한 뒤 새 아이템을 집음 (증발/복사 차단)
- 호버 툴팁: 가방, 장착 슬롯, 금고, 그리드 위 모듈에 상세 스탯 툴팁. 아이템을 잡고 이동 중에는 숨김
- 한글 폰트: Unity 6 TMP Dynamic SDF Font Asset 적용

**미드랍 천장 버그 상세 (코드 수정 시 참고)** — `ItemDropManager.TryDropItem()`

### 8-4. 미정 사항 (구현 전 결정)

1. 탈출 구역 생성 시점 (시작 즉시 탈출하는 전략 방지책)
2. 난이도 스케일링 기준 (스테이지 내부 시간 vs 런 누적)
3. 스탯 상한: 재장전 속도, 연사력, 치명타 확률, 수류탄 쿨감

   - 장전 계열 작동 모듈 초안 (무기 reloadTime 기준): 쉘 장전 = 1발씩 장전(1발당 reloadTime ÷ 탄창), 사격으로 중단 가능 / 드럼 탄창 = 탄창 증가 + 장전 시간 증가 / 2연장 = 탄창 2발 + 초고속 장전. 구현은 JU 장전 판정(예비탄 > 0)을 우회하는 Assets/Project 쪽 장전 래퍼 필요

10. 게임 클리어 조건 (현재 라운드가 무한히 이어지는 구조라 클리어 시점 정의 필요)
